# 🧠 Mental Health Risk Prediction System

A machine learning-powered web application that predicts an individual's mental health risk level based on demographic, lifestyle, behavioral, and psychological factors.

Built using **Python**, **Scikit-Learn**, and **Streamlit**, this project provides a production-grade interface for assessing mental health risk and generating personalized wellness recommendations.

---

## 🚀 Features

### Machine Learning Prediction
* Predicts Mental Health Risk Levels:
  * 🟢 **Low Risk**
  * 🟡 **Moderate Risk**
  * 🔴 **High Risk**

### Interactive Dashboard
* User-friendly, production-grade Streamlit interface with a responsive side-by-side columns layout.
* Modern typography (**Outfit** font) and elegant dark-teal styling.
* Dynamic right-panel results container (updates instantly upon submission).
* Sidebar resources featuring verified crisis support helplines (US/Canada/UK) and a global directory link.

### Risk Analysis
* Real-time risk level classification.
* Model prediction confidence score.
* Beautifully rendered Altair probability distribution bar chart.
* Personalized, actionable wellness recommendations.

### Data Inputs
The model considers multiple factors, including:

#### Demographic Information
* Age, Gender, Country, and Occupation

#### Lifestyle & Behavior
* Sleep Quality, Sleep Hours, Exercise Frequency, Screen Time, Work Hours Per Week, and Social Support

#### Psychological Indicators
* Stress Score, Anxiety Score, Depression Score, Academic/Job Pressure, and Financial Stress Score

#### Medical Background
* Therapy History and Family History of Mental Illness

## 🧠 Machine Learning Pipeline

The model was trained using a Mental Health Survey dataset containing demographic, behavioral, and psychological indicators.

### Data Preprocessing
The preprocessing pipeline is customized to fit the estimator type (scaled features for linear/distance models, raw features for tree-based models):
* **Ordinal Encoding**: Sleep Quality, Exercise Frequency
* **Binary Encoding**: Therapy History, Family History of Mental Illness
* **Label Encoding**: Social Support
* **One-Hot Encoding**: Gender, Country, Occupation
* **Feature Scaling**: `StandardScaler` (automatically bypassed for tree-based models to ensure correct class decision boundaries).

### Models Evaluated
* Logistic Regression
* Decision Tree
* K-Nearest Neighbors
* Random Forest
* Gradient Boosting

The final model used in this application is a **Decision Tree Classifier** optimized for prediction accuracy.

## ⚙️ Installation

### Clone Repository
```bash
git clone https://github.com/Gilbert-Baraza/mental-health-risk-predictor.git
cd mental-health-risk-predictor
```

### Create Virtual Environment
```bash
python -m venv venv
```

### Activate Environment
**Windows (Command Prompt / PowerShell):**
```powershell
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### Install Dependencies
```bash
pip install -r requirements.txt
```

## 📊 Example Workflow

1. Enter your demographic details in the **Demographics** column.
2. Provide sleep, exercise, and screen time details under **Lifestyle & Habits**.
3. Input self-reported psychological assessment scores under **Wellness History**.
4. Click **Predict Risk**.
5. Review the dynamically generated **Wellness Action Plan** containing:
   * Risk Classification card (Low / Moderate / High)
   * Prediction confidence score
   * Interactive Probability Analysis chart
   * Personalized Wellness Recommendations
   * Downloadable full prediction report

## 🌐 Deployment

### Streamlit Community Cloud
1. Push this project to your GitHub repository.
2. Log in to [Streamlit Community Cloud](https://share.streamlit.io/).
3. Click **New app**, select your repository, set the branch to `main`, and the entry point to `app.py`.
4. Click **Deploy**.

### Render
* **Service Type**: Web Service
* **Runtime**: Python
* **Build Command**: `pip install -r requirements.txt`
* **Start Command**: `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`

This application is intended for educational and decision-support purposes only.

The predictions generated by this system are not clinical diagnoses and should not replace professional mental health evaluation, diagnosis, or treatment.

If you or someone you know is experiencing immediate danger or distress, contact your local emergency services (e.g., 911, 999, 112) or reach out to a crisis helpline (such as calling/texting **988** in the US & Canada).
